# Habit Tracker

Daily habit checklist with a rolling 14-day grid.

## Features
- Add / remove habits
- Toggle completion per day
- Simple streak count
- localStorage persistence

## Limitations
- No accounts or cloud sync
- Streak is consecutive days ending today

## Stack
- Next.js App Router
- TypeScript
- Tailwind CSS
- localStorage persistence

## Run
```bash
npm install
npm run dev
```

## Honesty notes
- Portfolio mini-app showcase
- Not multi-tenant SaaS
